Sequence Diagram of Overlayr Workflow (Final Architecture)
======================================================
*Updated: 2026-02-07 (Latest Configuration)*

1. Capture Mechanism (การจับภาพ)
------------------------------------------------------
Overlayr ใช้ไลบรารี `mss` เป็นแกนหลักในการจับภาพ (High-performance screen shot)
[เทคนิคสำคัญ: Invisible Overlay]
- เราใช้ `SetWindowDisplayAffinity` (Windows API) เพื่อทำให้หน้าต่าง Overlay "ล่องหน" จากการจับภาพ
- **ข้อดี:** จับภาพได้ต่อเนื่องโดยไม่ต้องสั่ง Hide/Show หน้าต่าง ช่วยลดอาการกระพริบ (Flickering) และทำให้การทำงานลื่นไหลแบบ Real-time

2. Preprocessing (การเตรียมภาพ)
------------------------------------------------------
เป้าหมาย: แปลงภาพให้เป็น "ขาว-ดำ" (Binary) ที่คมชัดที่สุด เพื่อให้ Windows OCR อ่านได้แม่นยำ
ลำดับขั้นตอน (Pipeline Order & Parameters):
1. **[Upscale 2.0x]**
   - **Scale:** 2.0 เท่า
   - **Interpolation:** Bicubic (`cv2.INTER_CUBIC`)
   - *เหตุผล:* ขยายเพื่อให้เส้นตัวอักษรเล็กๆ (Small fonts) มีความหนาเพียงพอให้ OCR จับได้
2. **[Grayscale & CLAHE]**
   - **ClipLimit:** 2.0 (ค่าน้อยคือปรับคอนทราสต์เบาลง เพื่อไม่ให้ Noise เยอะเกินไป)
   - **TileGridSize:** (8,8) (ขนาดตารางที่ใช้คำนวณ)
   - *เหตุผล:* ปรับแสงให้เท่ากันทั้งภาพ (Equalization) ทำให้ตัวอักษรเด่นชัดขึ้น
3. **[Denoise (Median Blur)]**
   - **Kernel Size:** 5 (รัศมี 5 พิกเซล)
   - *เหตุผล:* ลบจุดรบกวน (Salt-and-pepper noise) ที่มักเกิดขึ้นหลังจากเร่งคอนทราสต์
4. **[Adaptive Threshold]**
   - **Method:** Gaussian C
   - **Block Size:** 11
   - **C (Constant):** 12 (ลดจาก 15 เพื่อเก็บรายละเอียดตัวอักษรบางที่อาจจะจาง)
   - *เหตุผล:* ตัดขอบตัวอักษรออกจากพื้นหลัง
5. **[Morphological Closing]**
   - **Kernel:** Rect (2,2)
   - *เหตุผล:* เชื่อมต่อเส้นตัวอักษรที่ขาดออกจากกัน (Repair broken fonts)
6. **[Clean Noise (CCA)]**
   - **Min Area:** 10 pixels
   - *เหตุผล:* ลบจุดดำเล็กๆ ที่ไม่ใช่ตัวอักษร
7. **[Finalize]** Invert สี (ตัวอักษรดำ พื้นขาว) และเติมขอบ (Padding) 50px 50px

3. OCR (การอ่านข้อความ)
------------------------------------------------------
- **Engine:** Windows Dictionary-based OCR (Offline)
- **Input:** ภาพขาว-ดำจากขั้นตอน Preprocessing
- **Features:** ทำงานเร็วมาก (Milliseconds), รองรับภาษาไทย/อังกฤษ/ญี่ปุ่น

4. Post-Processing & Logic (ตรรกะหลังการอ่าน)
------------------------------------------------------
1. **[Spell Check / Correction]**
   - ทำ **ก่อน** Validation เพื่อแก้ไขคำที่ OCR อ่านผิดเล็กน้อย (เช่น `th1s` -> `this`)
2. **[Validation Service]**
   - คัดกรองข้อความขยะ (Gibberish) โดยใช้กฎที่ผ่อนปรน (Relaxed Rules)
   - ยอมรับสัญลักษณ์ได้มากขึ้น (50%) เพื่อเก็บข้อความสั้นๆ หรือประโยคที่มีเครื่องหมายตกใจ
3. **[Translation]**
   - ส่งข้อความที่ผ่านการคัดกรองไปยัง Google Translate (Async)

5. Display & Performance (การแสดงผล)
------------------------------------------------------
- **Technology:** Tkinter Transparent Window
- **Behavior:**
  - สร้าง Overlay ทับตำแหน่งเดิมของข้อความ
  - แสดงผลลัพธ์ที่แปลแล้ว (Translated Text) บนพื้นหลังสีเข้มโปร่งแสง
- **Performance Loop:**
  - **Zero Delay:** `await asyncio.sleep(0)`
  - การทำงานเป็นรอบแบบทันที (Immediate Cycle) เพื่อให้การจับภาพและการแสดงผลตอบสนองไวที่สุด (Max FPS)

6. Authentication (ระบบยืนยันตัวตน)
------------------------------------------------------
- มีระบบตรวจสอบสิทธิ์การใช้งาน (Pro/Trial)
- เชื่อมต่อ Login ผ่าน Browser และตรวจสอบ Status ก่อนเริ่มทำงาน
