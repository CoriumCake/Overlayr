Sequence Diagram of Overlayr Workflow (Final Version)
======================================================
*Updated: 2026-02-06 (Latest Architecture)*

1. Capture Mechanism (การจับภาพ)
------------------------------------------------------
Overlayr ใช้ไลบรารี `mss` เป็นแกนหลัก (High-performance screen shot)
[เทคนิคสำคัญ: Invisible Overlay]
- เราใช้ `SetWindowDisplayAffinity` (Windows API) เพื่อทำให้หน้าต่าง Overlay "ล่องหน" ในสายตาของโปรแกรมจับภาพ
- ผลลัพธ์: เราสามารถจับภาพหน้าจอได้ตลอดเวลาโดยไม่ต้องซ่อน/แสดง Overlay ไปมา (No flickering) และ OCR จะไม่เผลออ่านข้อความแปลของตัวเอง

2. Preprocessing (การเตรียมภาพ)
------------------------------------------------------
เป้าหมาย: ทำภาพให้ "ขาว-ดำ" ชัดเจนที่สุด เพื่อให้ OCR อ่านง่าย (Optimized for Windows OCR)
ลำดับขั้นตอน (Pipeline Order):
1. [Upscale 2.5x] ขยายภาพ 2.5 เท่าด้วย Bicubic Interpolation เพื่อให้ตัวอักษรเล็กๆ มีรายละเอียดเส้นชัดเจน
2. [Grayscale & CLAHE] แปลงขาวดำและปรับ Equalization เพื่อเร่งคอนทราสต์ตัวอักษร
3. [Denoise] Median Blur เพื่อลบจุดรบกวน (Noise)
4. [Adaptive Threshold] แปลงเป็นภาพขาว-ดำ (Binary) ตัดพื้นหลังออก
5. [Clean Noise (CCA)] ใช้ Connected Component Analysis ลบฝุ่นจุดดำเล็กๆ ที่ไม่ใช่ตัวอักษร
6. [Finalize] Invert สี (ตัวอักษรดำ พื้นขาว) และเติมขอบ (Padding)

3. OCR (การอ่านข้อความ)
------------------------------------------------------
- Engine: **Windows Dictionary-based OCR** (รวดเร็ว, ไม่ต้องใช้เน็ต)
- Input: ภาพจากขั้นตอนที่ 2
- Output: ข้อความดิบ (Raw Text) และ ตำแหน่ง (Bounding Boxes)

4. Post-Processing (การประมวลผลก่อนแปล)
------------------------------------------------------
1. [Spell Check & Correction]
   - ทำ **ก่อน** Validation เพื่อกู้คืนคำที่อ่านผิด
   - ตัวอย่าง: `th1s` -> `this`
2. [Validation]
   - กรองข้อความขยะทิ้ง (Gibberish Filter)
   - กฎเกณฑ์ผ่อนปรน (Relaxed Rules): ยอมรับสัญลักษณ์ได้ 50% ของความยาว เพื่อไม่ให้ตัดคำที่มีเครื่องหมายตกใจหรือจุดทิ้ง

5. Translation (การแปลภาษา)
------------------------------------------------------
- Engine: **Google Translate (Async)**
- Input: ข้อความภาษาอังกฤษ (หรือญี่ปุ่น/เกาหลี) ที่ผ่านการกรองแล้ว
- Output: ข้อความภาษาไทย

6. Display (การแสดงผล)
------------------------------------------------------
- Technology: **Tkinter Transparent Window** (Click-Through)
- การแสดงผล:
  - วาดข้อความผลลัพธ์ (Translated Text) ทับตำแหน่งเดิมบนหน้าจอ
  - มีพื้นหลังสีเข้มโปร่งแสง (Semi-transparent background) เพื่อให้อ่านง่าย
  - **Performance:** Loop Delay = 0 วินาที (Real-time updates) เพื่อความลื่นไหลสูงสุด
