# รายละเอียดกระบวนการทำงาน (Pipeline Detail) 🛠️🚀
อัปเดตล่าสุด: 2026-02-12

ระบบทำงานเป็นลำดับขั้น (Sequential Pipeline) ดังนี้ครับ:

## 1. การจับภาพ (Screen Capture) 📸
- **Module:** `wgc_capture.py`
- **Technology:** Windows Graphics Capture (WGC)
- **Process:**
  - จับภาพหน้าต่างที่เลือกแบบ Real-time (60fps แต่ดึงมาใช้จริงตามจังหวะ Loop)
  - ตัดส่วนขอบหน้าต่าง (Client Area) ออกเพื่อให้ได้เฉพาะเนื้อหา
  - ส่งภาพ `PIL.Image` เข้าสู่ระบบประมวลผล

## 2. การเตรียมภาพ (Preprocessing) 🧹
**เป้าหมาย:** ทำภาพให้ "สะอาดที่สุด" และ "ตัวหนังสือชัดที่สุด" ก่อนส่งให้ OCR
- **Module:** `engine.py` -> `process_image`

### 2.1 Smart Scaling (ปรับขนาดอัจฉริยะ)
- **ภาพใหญ่ (>1600px):** ย่อลง (Downscale) เพื่อความเร็ว (ประมวลผลไวขึ้น 3-4 เท่า)
- **ภาพเล็ก (<800px):** ขยายขึ้น (Upscale 2x) เพื่อให้ OCR อ่านตัวหนังสือเล็กๆ ออก
- **ภาพปกติ:** ใช้ขนาดเดิม

### 2.2 Simplified Pipeline (Requested)
- **Grayscale:** ภาพต้นฉบับแปลงเป็นขาว-ดำ
- **CLAHE:** ปรับ Contrast ให้ชัด
- **ส่งตรงเข้า OCR:** ใช้งานภาพที่สะอาดที่สุดโดยไม่ผ่าน Thresholding หรือ Dual Mask เพื่อเก็บรายละเอียดตัวอักษรให้ดีที่สุด
- (ยกเลิก Dual Polarity Masking ที่ซับซ้อนออก เพื่อความรวดเร็วและความเที่ยงตรงของ OCR ตัวอักษรดั้งเดิม)

## 3. การแปลงภาพเป็นข้อความ (OCR) 👁️
- **Engine:** **RapidOCR** (OnnxRuntime)
- **Input:** ภาพขาวดำที่ผ่านการ Preprocess แล้ว
- **Output:** รายการของ `(Bounding Box, Text, Confidence)`

## 4. การจัดกลุ่มข้อความ (Text Grouping / Clustering) 📦
- **Module:** `engine.py` -> `_merge_text_blocks`
- ระบบเลือกใช้ Logic ตามโหมดที่ผู้ใช้เลือก:

### 4.1 โหมด Document (Lines) - สำหรับเอกสาร/เกม
- **Line Forming:** รวมเศษคำที่อยู่ในแนวเดียวกันเป๊ะๆ (ห่างกันไม่เกิน 15px) ให้เป็นบรรทัดเดียว
- **Smart Paragraph:**
  - รวมบรรทัดเข้าเป็นย่อหน้า (Paragraph) ถ้าบรรทัดอยู่ชิดกัน
  - **ตัดจบย่อหน้า** ถ้าเจอช่องว่างบรรทัดกว้างผิดปกติ
  - **แยกหัวข้อ (Header)** ถ้าเจอตัวอักษรที่ขนาดใหญ่/เล็กต่างกันชัดเจน

### 4.2 โหมด Manga (Groups) - สำหรับการ์ตูน
- **Clustering:** มองหา "กลุ่มก้อน" ของข้อความ
- รวมข้อความเข้าด้วยกันถ้า:
  - มีส่วนที่ซ้อนทับกันในแนวนอน (Horizontal Overlap)
  - อยู่ใกล้กันในแนวตั้ง (ไม่เกิน 2 เท่าของความสูงบรรทัด)
- ผลลัพธ์คือได้ text ทั้งก้อนบับเบิ้ลมาแปลรวดเดียว

## 5. การแปลภาษา (Translation) 🌍
- **Module:** `google_translate.py` & `engine.py`

### 5.1 Caching (ระบบจำคำแปล)
- ก่อนแปล จะเช็คใน Cache 100 คำล่าสุด
- **Logic ใหม่:** เช็คคู่กับ "ภาษาปลายทาง" ด้วย (Original Text + Target Language)
- ถ้าเจอ (Hit): ดึงคำแปลเดิมมาแสดงทันที (0ms delay)
- ถ้าไม่เจอ (Miss): ส่งไปแปลใหม่

### 5.2 Translation Service
- ส่งข้อความไปที่ Google Translate API (Async)
- รับคำแปลกลับมา

## 6. การแสดงผล (Overlay Display) 🖼️
- **Module:** `overlay.py` -> `OverlayWindow`
- วาดกล่องข้อความทับลงบนตำแหน่งเดิมในหน้าจอ (Coordinates ตรงเป๊ะ)
- **Transparent Fix:** เช็คค่าสี ถ้าเป็น 'transparent' จะไม่วาดเส้นขอบ เพื่อความสวยงามและกันโปรแกรม Crash
- แสดงผลด้วย Tkinter (TopMost Window) ที่เจาะทะลุ Click-through ได้

---

**สรุป Flow:**
`Capture` -> `Preprocess (Dual Mask)` -> `OCR` -> `Grouping (Smart)` -> `Translate (Cache check)` -> `Overlay Update`
