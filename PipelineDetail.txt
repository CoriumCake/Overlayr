================================================================================
 core/engine.py — AsyncEngine (Singleton)
================================================================================
  คลาส: AsyncEngine
  หน้าที่: ควบคุมการทำงาน OCR → แปลภาษา → ส่งผลลัพธ์ไปแสดงผล

  __init__()
    → สร้าง WindowsOCREngine, GoogleTranslateService, TextPostProcessor
    → สร้าง Translation Cache แบบ LRU (OrderedDict, ขนาด 100)
    → ตั้ง _is_running = False

  set_status_callback(callback)
    → ส่ง callback สำหรับอัปเดตสถานะ UI ไปให้ OCR service
    → ตั้งค่า source="en", target="th" เริ่มต้น

  set_loop(loop)
    → บันทึก asyncio event loop สำหรับใช้งานภายใน

  _handle_task_result(future)
    → จัดการ error จาก async task ที่ถูกยิงแล้วลืม (fire-and-forget)

  warmup()
    → เรียก warmup() บน OCR service และ Translator
    → โหลดโมเดลล่วงหน้าเพื่อลด latency ครั้งแรก

  async update_languages(source, target)
    → อัปเดตภาษา source/target ทั้งใน Translator และ OCR engine
    → เคลียร์ cache ถ้าภาษาเปลี่ยน

  async process_image(image, step_callback, skip_translation, merge_mode)
    → Pipeline หลักของระบบ:
      1. แปลง PIL Image → OpenCV BGR
      2. รัน OCR ด้วย WindowsOCREngine.extract_text()
      3. ทำความสะอาดข้อความด้วย TextPostProcessor
      4. กรองข้อความด้วย ValidationService.is_valid_text()
      5. ดึงสีพื้นหลังของแต่ละ bbox (bg_color)
      6. รวมกลุ่มข้อความด้วย _merge_text_blocks()
      7. ตรวจ/ใช้ Translation Cache (LRU)
      8. แปลภาษา batch ที่ยังไม่ได้แปล
      9. คืน list ของ {bbox, original, translated, bg_color}
    → รองรับ step_callback("OCR"|"MERGED"|"TRANSLATED", data) สำหรับ debug

  _merge_text_blocks(elements, mode)
    → รวมกลุ่ม text box ที่อยู่ใกล้กัน
    → mode="paragraph" (Manga): Clustering แนวตั้ง+แนวนอน
    → mode="line" (Document): จัดกลุ่มบรรทัด → จัดกลุ่มย่อหน้า
    → ขั้นแรกกรอง box ซ้อนกัน (>50% overlap = nested, รวมหรือทิ้ง)
    → inner function get_vals(el): คืน (x, y, w, h) จาก bbox dict
    → inner function merge_cluster(items): รวม list ของ element → element เดียว
    → inner function get_cluster_pos(c): คืน top-left ของกลุ่ม
    → สำหรับ Paragraph Mode: จัดเรียง cluster ตาม Row-Column (Y แล้ว X)

  stop()
    → หยุดการทำงาน loop, ยกเลิก async task

 core/capture_engine.py — CaptureEngine (Singleton)
================================================================================
  คลาส: CaptureEngine
  หน้าที่: ดักจับภาพจากหน้าจอ (MSS) หรือหน้าต่าง (WGC)

  __init__()
    → ตั้งค่า mode="screen", target=None, roi=None
    → สร้าง WGCCapture instance

  set_source(mode, target)
    → กำหนด source ใหม่ (screen หรือ window)
    → หยุด WGC เสมอก่อน, ถ้า mode="window" → เริ่ม WGC session ใหม่
    → เคลียร์ ROI เมื่อเปลี่ยน source

  set_roi(roi)
    → ตั้ง Region of Interest เป็น tuple (x_ratio, y_ratio, w_ratio, h_ratio)
    → ค่า 0.0–1.0 เทียบกับขนาด target

  capture()
    → ดักจับภาพปัจจุบัน
    → mode="screen": ใช้ MSS ดักจับจอแสดงผล, รองรับ ROI
    → mode="window": ใช้ WGCCapture.get_latest_frame(), ใช้ pygetwindow ดึง bounds
    → คืน (PIL.Image, bounds_dict{left,top,width,height}) หรือ (None, None)

  get_thumbnail(mode, target, size)
    → สร้างภาพตัวอย่างขนาดเล็ก
    → mode="screen": ดักจับจอ → resize
    → mode="window": ใช้ PrintWindow API (Win32) ดักจับหน้าต่างแม้จะซ่อนอยู่ → resize


================================================================================
 core/post_processing.py — TextPostProcessor
================================================================================
  คลาส: TextPostProcessor
  หน้าที่: แก้ไขและทำความสะอาดข้อความที่ได้จาก OCR

  __init__(dictionary_path)
    → โหลด SymSpell dictionary (English) สำหรับแก้คำสะกด
    → ถ้าหา dict ไม่เจอ → ปิดการแก้ไข

  clean_text(text)
    → ลบ OCR artifacts ด้วย regex:
      - ลบ |-_= ที่อยู่โดดๆ ระหว่างคำ
      - แก้ ligature (ﬁ→fi, ﬂ→fl)
    → คืน string ที่สะอาดแล้ว

  _apply_custom_rules(text)
    → แก้ไขการอ่านผิดที่พบบ่อยด้วย regex:
      - Z0/ZO → 30 (ตัวเลข)
      - O1D → OLD
      - Y3AR → YEAR
      - 0 ที่ติดกับตัวอักษร → O (เช่น H0ME → HOME)
    → คืน string ที่แก้ไขแล้ว

  correct_text(text)
    → แก้คำสะกดด้วย SymSpell lookup_compound (max edit distance 2)
    → ก่อนแก้คำจะเรียก _apply_custom_rules() ก่อน
    → คืน text ที่ถูกต้องที่สุด หรือ text เดิมถ้าหาไม่เจอ

  fuzzy_match_custom(text)
    → จับคู่กับ custom_terms list โดยใช้ fuzz.ratio (Levenshtein)
    → ถ้า score > 85% → คืน best match
    → ใช้เป็น fallback สำหรับคำเฉพาะทาง (เกม/มังงะ)


================================================================================
 core/wgc_capture.py — Windows Graphics Capture (Pure ctypes)
================================================================================
  [ฟังก์ชัน helper ระดับ module]

  check_hresult(hr, msg)
    → ตรวจ HRESULT จาก COM call, โยน OSError ถ้าผิดพลาด

  ro_get_activation_factory(class_id_str, iid)
    → เรียก RoGetActivationFactory เพื่อดึง WinRT Factory pointer
    → โหลด combase.dll / roapi.dll ด้วย ctypes.WinDLL
    → ใช้ WindowsCreateString สร้าง HSTRING จาก class name
    → คืน factory_ptr (c_void_p)

  create_d3d11_device_ptr()
    → สร้าง D3D11 Device ด้วย D3D11CreateDevice (Hardware, BGRA support)
    → Query IDXGIDevice จาก device
    → เรียก CreateDirect3D11DeviceFromDXGIDevice → คืน IDirect3DDevice (WinRT pointer)

  create_capture_item(hwnd)
    → สร้าง IGraphicsCaptureItem จาก HWND
    → ดึง IGraphicsCaptureItemInterop factory ผ่าน RoGetActivationFactory
    → เรียก CreateForWindow(hwnd) บน VTable[6]
    → ถ้าล้มเหลว → ลอง CreateForMonitor แทน
    → คืน item_ptr (c_void_p)

  create_frame_pool(device_ptr, pixel_format, num_buffers, size_width, size_height)
    → สร้าง IDirect3D11CaptureFramePool
    → เรียก CreateFreeThreaded บน factory VTable[6]
    → คืน pool_ptr (c_void_p)

  create_session(item_ptr, pool_ptr)
    → สร้าง IGraphicsCaptureSession จาก pool และ item
    → เรียก CreateCaptureSession บน pool VTable[10]
    → คืน session_ptr (c_void_p)

  start_session(session_ptr)
    → เรียก StartCapture บน session VTable[6]
    → เริ่มการดักจับ

  คลาส: GUID(Structure)
    __init__(guid_str): แปลง GUID string → ctypes Structure
    __str__(): แปลง GUID Structure กลับเป็น string

  คลาส: WGCCapture
  หน้าที่: ห่อหุ้มการดักจับ WGC ทั้งหมดในรูปแบบ OOP

    __init__()
      → ตั้งค่า device_ptr, item_ptr, pool_ptr, session_ptr = None
      → สร้าง threading.RLock

    initialize()
      → เรียก RoInitialize (WinRT COM init) จาก roapi.dll หรือ combase.dll
      → ถ้าผิดพลาด → ลอง CoInitializeEx แทน
      → เรียก create_d3d11_device_ptr() และเก็บ device_ptr

    start(target)
      → รับ dict ที่มี hwnd/id
      → เรียก initialize() ถ้ายังไม่ได้ init
      → สร้าง capture item จาก HWND
      → ดึงขนาดหน้าต่าง (VTable[7] GetSize)
      → ถ้าหน้าต่าง minimized (ขนาด ≤50px) → ตั้ง running=True แล้วรอ
      → สร้าง frame pool และ session → เริ่ม session
      → ตั้ง running=True

    get_latest_frame()
      → ถ้า pool ยังไม่ได้สร้าง (window เพิ่งถูก restore) → สร้าง pool ก่อน (Lazy Init)
      → เรียก TryGetNextFrame บน pool VTable[7]
      → ถ้ามี frame:
          - ดึง ContentSize (VTable[8]) ตรวจขนาดเปลี่ยนไหม → อัปเดต current_size
          - GetSurface (VTable[6]) → GetInterface IDirect3DDxgiInterfaceAccess
          - ดึง ID3D11Texture2D จาก surface
          - สร้าง Staging Texture (CPU-readable) ถ้ายังไม่มีหรือขนาดเปลี่ยน
          - CopyResource(context, staging, texture) → Map → อ่าน pixel data
          - สร้าง PIL.Image จาก raw bytes (BGRA format)
          - Unmap, Release frame
      → คืน PIL.Image หรือ None

    stop()
      → ตั้ง running=False
      → Release session_ptr, pool_ptr, item_ptr ผ่าน COM Release (VTable[2])
      → inner function safe_release(ptr): Release COM pointer อย่างปลอดภัย

 services/auth_service.py — AuthService
================================================================================
  คลาส: AuthService
  หน้าที่: จัดการ Login, Session, Subscription, Deep Link

  __init__()
    → สร้างโฟลเดอร์ ~/.overlayr สำหรับเก็บ session
    → โหลด session ที่มีอยู่ (load_session)
    → ลงทะเบียน Protocol Handler (register_protocol)

  register_protocol()
    → เขียน Windows Registry (HKCU\Software\Classes\overlayr)
    → ทำให้โปรแกรมรองรับ URL scheme: overlayr://
    → ตั้ง command ให้ชี้ไปที่ exe หรือ main.py (สำหรับ dev mode)

  process_launch_args(args)
    → ตรวจ sys.argv ว่ามี "overlayr://" ไหม
    → ถ้ามี → เรียก handle_deep_link()

  handle_deep_link(url)
    → แยก overlayr://auth?token=...&uid=... ด้วย urlparse
    → บันทึก session และดึงข้อมูล user จาก Identity Toolkit

  save_session(uid, token)
    → บันทึก uid, token, user_data ลงไฟล์ auth_session.json

  load_session()
    → โหลด uid, token, user_data จาก auth_session.json (ถ้ามี)

  has_feature(feature_key)
    → ตรวจว่า feature_key อยู่ใน active_features หรือไม่ (bool)

  _sync_features_from_profile(profile)
    → อัปเดต active_features จาก Firestore profile dict
    → รองรับทั้ง list และ string จาก Firestore REST API

  get_subscription_status()
    → ตรวจสอบ:
      1. Trial ในเครื่อง (7 วันนับจาก first_run)
      2. Firestore profile (isPro, expiryDate)
    → คืน ('pro'|'trial'|'expired'|'none', days_left)
    → Sync active_features จาก Firestore ด้วย

  _check_local_trial()
    → อ่านไฟล์ trial_config.json
    → ถ้าไม่มี → สร้างใหม่ (first_run = ตอนนี้)
    → คืน {active: bool, days_left: int}

  _fetch_firestore_profile_sync()
    → GET Firestore REST API เพื่อดึง user document
    → แกะ Firestore field types (booleanValue, stringValue, etc.)
    → คืน dict {field: value}

  _fetch_firestore_profile()
    → ห่อ _fetch_firestore_profile_sync ใน ThreadPoolExecutor
    → คืนผลลัพธ์ภายใน 15 วินาที (non-blocking)

  logout()
    → ล้าง uid, token, user_data, active_features
    → ลบไฟล์ auth_session.json

  _fetch_user_details_sync()
    → POST ไปที่ Identity Toolkit accounts:lookup
    → อัปเดต user_data (photoUrl, displayName, email)
    → บันทึก session ใหม่

  fetch_user_details()
    → ห่อ _fetch_user_details_sync ใน ThreadPoolExecutor (non-blocking)

  get_user_info()
    → คืน dict ที่มี uid, logged_in, pro, photo_url, display_name, email

 services/local_translator.py — LocalTranslatorService (Singleton)
================================================================================
  คลาส: LocalTranslatorService
  หน้าที่: แปลภาษาด้วยโมเดล facebook/m2m100_418M (ออฟไลน์, CUDA/CPU)

  __init__(source, target)
    → ตรวจ CUDA availability
    → ตั้ง model_name = "facebook/m2m100_418M"
    → ตั้ง flag _is_loading, _load_error

    → โหลด M2M100Tokenizer และ M2M100ForConditionalGeneration
    → โหลดขึ้น GPU (cuda) ถ้ามี, ไม่งั้น CPU
    → ตั้ง model.eval() เพื่อปิด dropout
    → ถ้าโหลดเคยผิดพลาดแล้ว → ข้ามเพื่อประหยัด resource

    → รองรับ string เดียวหรือ list
    → ตรวจ cache ก่อน (key = "{src}_{tgt}_{text}")
    → Tokenize ด้วย src_lang → generate ด้วย forced_bos_token_id
    → ตั้งค่า: max_new_tokens=64, num_beams=1 (greedy), repetition_penalty=1.5
    → อัปเดต cache, Evict ถ้าเกิน 2000 รายการ
    → คืน string หรือ list

 services/ocr.py — OCREngine (Singleton, EasyOCR)
================================================================================
  คลาส: OCREngine (ใช้ EasyOCR — รุ่นเก่า/สำรอง)

  __init__(languages, gpu)
    → Lazy init (ไม่โหลด reader ทันที)

    → ถ้าผิดพลาด → fallback เป็น ['ja', 'en']

  warmup()
    → โหลด reader ล่วงหน้า (thread-safe ด้วย Lock)

================================================================================
 services/ocr_preprocessor.py — เตรียมภาพก่อน OCR
================================================================================
  [ฟังก์ชัน standalone]

  preprocess_image_for_ocr(image_source)
    → รับ path หรือ numpy array
    → Grayscale → Scale 2x (INTER_CUBIC) → Sharpen (kernel 3x3)
    → คืน (processed_img, scale_factor=2.0)

  detect_text_regions(image_source, bubbles)
    → ตรวจหาบริเวณที่น่าจะมีข้อความด้วย Morphological Dilation
    → ถ้ามี bubbles: แยกประมวลผลภายใน/ภายนอก bubble แต่ละอัน
    → คืน list ของ (x, y, w, h)

  detect_speech_bubbles(image_source)
    → ตรวจหา speech bubble (บริเวณสีขาว) ด้วย threshold=215
    → วิเคราะห์ contour ด้วย RETR_CCOMP, fill บริเวณสีขาว
    → แยก bubble ที่ซ้อนกันด้วย recursive_split_bubble()
    → inner function recursive_split_bubble(c):
        - วิเคราะห์ convexity defects ของ contour
        - inner function calculate_angle(pt, p_prev, p_next): คำนวณมุมที่จุด defect
        - ถ้าพบ deep defects 2 จุดที่ห่างกัน → ตัดแบ่ง bubble ออกเป็น 2 ส่วน
        - ตรวจ ratio พื้นที่ (>0.05) เพื่อยืนยันการตัด
        - Recurse ต่อเนื่อง
    → คืน list ของ contours

  split_merged_contours(image_bin, contours, min_area, draw_on, color, recursion_depth)
    → แยก contour ที่รวมกันด้วย Horizontal Projection Profile
    → ขั้นตอน:
        1. คำนวณ projection แนวนอน (sum ต่อ row)
        2. หา gap (row ที่มี pixel น้อย <12%)
        3. หา gap ที่ใกล้กลางภาพที่สุด
        4. ตัดแนวนอน → Recurse
        5. ถ้าหา gap แนวนอนไม่ได้ → ลอง gap แนวตั้ง
    → คืน list ของ contours ที่แยกแล้ว

  apply_cuts_to_original(image_path)
    → อ่านภาพ → Scale 2x → Sharpen → Binary threshold
    → ตรวจหา speech bubble → ลบ border ของ bubble
    → หา contour → เรียก split_merged_contours()
    → คืน numpy array ของภาพที่มีเส้น cut แล้ว (scale กลับ 1x)

 services/windows_ocr.py — WindowsOCREngine + helper functions
================================================================================
  คลาส: TextLine
    → เก็บ text, words (list of Rect), sources (set ของ technique names)

  คลาส: Rect
    → เก็บ x, y, width, height (พิกัด bounding box)

  [ฟังก์ชัน async helper]

  async get_software_bitmap_from_file(file_path)
    → อ่านไฟล์ภาพจาก path → สร้าง SoftwareBitmap ผ่าน WinRT StorageFile API
    → คืน SoftwareBitmap หรือ None

  async run_ocr(image_source, language, technique)
    → รัน Windows OCR engine ด้วยเทคนิคการประมวลผลภาพที่ระบุ
    → technique รองรับ:
        'baseline'         — Grayscale + Scale 2x + Sharpen
        'threshold'        — Adaptive Threshold (Gaussian)
        'simple_threshold' — Otsu Threshold
        'clahe'            — CLAHE contrast enhancement
        'inverted'         — Invert ภาพ
        'thicken'          — Erode kernel (ทำให้ตัวอักษรหนาขึ้น)
        'shear'            — Shear ซ้าย (skew เอียงซ้าย)
        'shear_right'      — Shear ขวา
        'rotate'           — หมุน +5 องศา (CCW)
        'rotate_cw'        — หมุน -5 องศา (CW)
    → แปลงภาพ processed → บันทึกลง temp file → SoftwareBitmap → OCR
    → คืน (ocr_result, scale_factor, processed_img, duration)

  correct_geometry(ocr_result, technique, scale, img_shape, matrix_mode)
    → แปลงพิกัด word bounding_rect กลับสู่ original coordinate space
    → ชดเชย shear, rotation (affine transform inverse), padding
    → คืน list ของ TextLine ที่มีพิกัดถูกต้อง

  merge_text_lines(base_lines, new_lines)
    → รวม TextLine จากเทคนิคต่างๆ เข้าด้วยกัน
    → เกณฑ์การรวม: similarity (SequenceMatcher) + overlap area + Y distance
    → ป้องกัน duplicate และอัปเดต sources set
    → ถ้า text ใหม่ยาวกว่า/ดีกว่า → อัปเดต text เดิม

  calculate_match_score(candidates, references)
    → คำนวณคะแนนความตรงกันระหว่าง candidates และ references
    → ใช้ similarity + area overlap ratio
    → ใช้ตัดสินว่าจะใช้ forward หรือ inverse transform สำหรับ rotate

  filter_redundant_geometry(base_lines, geom_lines, technique_name)
    → กรอง TextLine ที่ซ้ำกับ base_lines ออก
    → เกณฑ์: overlap_ratio > 30% และ text_similarity > 40% หรือ substring
    → คืน list ของ TextLine ที่ไม่ซ้ำกัน

  group_text_lines(final_lines, image)
    → จัดกลุ่ม TextLine ตาม proximity (ใช้ Y และ X distance)
    → คืน list ของ group dict {type, id, lines}

  คลาส: WindowsOCREngine
  หน้าที่: รัน OCR ด้วย 10 เทคนิคพร้อมกัน (asyncio.gather) และรวมผลลัพธ์

    __init__()
      → ตั้ง _language="en", _status_callback=None

    set_callback(callback)
      → บันทึก UI status callback

    set_language(lang_code)
      → map lang code → BCP-47 (เช่น "ja" → "ja-JP")
      → อัปเดต self._language

    async extract_text(image)
      → แปลง PIL Image → CV2 BGR
      → รัน 10 เทคนิค OCR พร้อมกัน (asyncio.gather):
          task1=baseline, task2=threshold, task3=inverted, task4=thicken,
          task5=shear, task6=rotate, task7=rotate_cw, task8=shear_right,
          task9=simple_threshold, task10=clahe
      → รวมผลลัพธ์ด้วย merge_text_lines() ตามลำดับ
      → ตรวจ redundant geometry สำหรับ shear/rotate techniques
      → สำหรับ rotate: เลือก forward vs inverse transform ที่ score สูงกว่า
      → แปลง TextLine → output format: [(bbox_4pts, text, conf=0.95), ...]
      → คืน list ของ tuple (bbox, text, confidence)

    warmup()
      → stub ว่างๆ

 services/validation_service.py — ValidationService
================================================================================
  คลาส: ValidationService
  หน้าที่: ตรวจกรองข้อความ OCR ที่ไม่ใช่เนื้อหาจริง

  _has_asiatic_chars(text) [staticmethod]
    → ตรวจว่ามีอักขระ Thai, CJK, Hiragana/Katakana, Hangul ไหม

  is_valid_text(text, source_lang) [staticmethod]
    → ขั้นตอนการกรอง:
      1. ความยาว 2–500 ตัวอักษร
      2. ไม่เป็น URL / domain / path (regex UI_PATTERNS)
      3. ตรวจ symbol+digit density (>70% บน text สั้น → ตัดทิ้ง)
      4. ตรวจตาม source language:
         - "en": ต้องไม่มีอักขระ Asiatic, ต้องมี vowel, ต้องมีสัดส่วน letter >60%
                 (ยกเว้น abbreviation เช่น Mr., Dr.)
                 ถ้ายาว >20 chars → ใช้ langdetect ตรวจสอบ
         - "th": ต้องมีอักขระ Thai อย่างน้อยหนึ่งตัว
      5. ตรวจ mixed gibberish (digit+symbol > 2x letters บน text สั้น)
      6. Pure digit/symbol string ที่ความยาว <10 → ตัดทิ้ง
      7. Alpha ratio < 50% บน text ยาว >10 → ตัดทิ้ง
    → คืน True ถ้าผ่านการตรวจ
